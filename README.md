# Office Viewer Pack for Word, Excel, PowerPoint & PDF Preview

One install adds four free, read-only viewers for Office files and PDF. Each one works offline.

Your files stay on your machine. The viewers do not change your files, and they need no account.

| Viewer | Opens | What you get |
|---|---|---|
| [DOCX Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.docx-viewer-vscode) | Word: .docx, .doc, .odt, .dotx, .docm | Word documents in dark mode, with outline, search and tables |
| [XLSX Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.table-viewer-vscode) | Excel: .xlsx, .xls, .xlsm, .ods, .csv, .tsv, .parquet | Sort and filter up to 1,000,000 rows, no Python needed |
| [PPTX Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.pptx-slide-viewer) | PowerPoint: .pptx, .ppt, .ppsx, .potx | Slides, speaker notes and all slide text |
| [PDF Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.pdf-viewer-dark) | .pdf | Dark pages that keep photos in their real colors, search with highlights, outline |

Need only Word files? Install DOCX Viewer alone. You can uninstall any viewer from the pack, and the others keep working.

## How to use

Install the pack, then click a file in the Explorer. It opens in the matching viewer. To open a file as text, right-click it and choose "Open With...", then "Text Editor".

These are viewers. To edit a document, use the app that made it.

## Free and Zovo Pro

The four viewers in this pack are free and complete. Nothing in them is paid, and every feature they have today stays free.

Zovo Pro is optional: USD 19, paid once, for every Zovo VS Code viewer. Today it adds Pro features in [Hex Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.zovo-hex-viewer) (binary templates with a structure view, bookmarks, checksums and compare reports) and [DOCX Viewer](https://marketplace.visualstudio.com/items?itemName=zovo.docx-viewer-vscode) (redline export as a Word file with tracked changes, and folder compare). Pro features that come to other Zovo viewers later are included, the viewers in this pack too if they get any. See [what Zovo Pro includes](https://theluckystrike.github.io/zovo-plugin-factory/pro.html).
